Proyecto desarrollado para el curso de Data Analytics de Coderhouse. Consiste en el análisis y la comparativa de las frecuencias o rutas
aéreas hacia y desde Argentina, durante el período comprendido entre el año 2022 y el 2024. Para esto, el dataset utilizado ha sido obtenido del portal Datos Argentina, cuya finalidad es poner datos públicos al alcance de la población en general. En este caso en
particular, se ha recurrido al recurso elaborado por la Dirección Nacional de Mercados y Estadística, de la Subsecretaría de Turismo el 23 de agosto de 2023, con la última actualización del 23 de enero de 2025 (https://datos.gob.ar/dataset/turismo-conectividad-aerea/archivo/turismo_aab49234-28c9-48aba978-a83485139290).
Se incluye la base de datos utilizada. Sin embargo, respecto al origen de los datos (data), cada archivo cargado corresponde a una hoja del archivo original de Excel. Se recomienda unirlas manteniendo el nombre de cada archivo para la hoja y dando por nombre al archivo resultante "Base agregada de frecuencias aéreas_2022,2023,2024 NORMALIZADA". De esa forma, será posible modificar el parámetro creado en Power Query y poder cargar los datos.
Por otro lado, la documentación del proyecto (docs) describe el trabajo realizado, en el marco de la entrega del curso. Mientras que, el tablero realizado en Power BI (dashboard) puede explorarse ajustando el parámetro para el origen de los datos local.
